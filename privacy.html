Privacy

Privacy

Coilborn collects nothing. It has no accounts, no ads, no analytics and no tracking, and it never connects to the internet — there is no networking code in it at all.

What it keeps on your device

One small file in the app's own folder: the phase you reached, your badges and records, the rewards you earned and your settings. It never leaves your device, and uninstalling removes it.

Permissions

None. If a store listing mentions camera, microphone or Bluetooth, that is only because the framework the game is built on includes support for them. Coilborn uses none of it.

This site

A static page on GitHub Pages. No cookies, no third-party scripts. GitHub may keep standard server logs.
