# Coilborn — website

Static site (no build step, no npm) for Coilborn, served by GitHub Pages from `main`.

**Do not hand-edit:** it is generated from the game repo with
`python3 tools/make_website.py ../coilborn-website` (copy, theme and screenshot list in `tools/website.json`).

- `index.html` — home
- `privacy.html` — privacy policy (URL required by App Store Connect)
- `support.html` — support (the other required URL)
- `img/` — icon, screenshots and the App Store preview video
